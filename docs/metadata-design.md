# メタデータ設計の背景

`outputs/*_metadata.json` の記録内容は [README.md](../README.md) の「出力と再現メタデータ」、
実装は `cardgen.py` にあります。この文書はそこから読み取れない**理由**だけを残します。
AGENTS.md には結論の規則だけを置き、根拠はここに置きます。

## ノード種別を列挙せず、全ノードを記録する

`snapshot_node_inputs()` は全ノードのリテラル入力を記録します。

列挙方式にすると、`SamplerCustomAdvanced` のように設定を自前で持たないノードを使う
ワークフローで cfg・steps・sampler がまるごと記録から抜けます。FLUX.2のグラフで実際に
抜けていました。新しいノード種別を足すたびに同じ穴が空く方式は採用しません。

## 記録しない3つ

- プロンプト本文 — `prompt` / `negative` に別途あるため
- seed — `results` にある。テンプレート側の値は古いので、記録すると誤解を招く
- 入力画像名 — 呼び出し元のprivateプロジェクトに属する情報のため

## 2種類のワークフローハッシュ

`workflow_sha256` はファイル、`queued_workflow_sha256` は実際に送信したグラフです。
ワークフローを書き換えて比較実験をした場合、この2つがなければ後から群を区別できません。

## ファイル全体のSHA-256でモデルを同定しないこと

`sha256` はファイル全体のハッシュで、**safetensorsヘッダのパディング1つで変わります**。
WAI v17 を Civitai からダウンロードしたファイルは、Civitai が掲載している SHA-256 と
一致しませんが、重みは同一でした。差はヘッダの `__spacer` フィールドです。

配布元と突き合わせるときは `weights_sha256` を使います。safetensors ヘッダの
`modelspec.hash_sha256` から読み、Civitai の `AutoV3` と直接比較できます。
`0x` 接頭辞は正規化して除去してあります。

用途の使い分け:

- `sha256` — 同じファイルで再現したかの判定に使う
- `weights_sha256` — 配布元との同一性の主張に使う

## 判定できないときは null を返す

`safetensors_weight_identity()` は例外を投げません。modelspec を持たない safetensors、
`.pth` のような別形式、壊れたヘッダはすべて `null` を返します。**持っていない情報を
持っているかのように記録しない**ためです。生成は止めません。

## モデルディレクトリは環境変数で渡す

`model_files` のハッシュには ComfyUI の models ディレクトリが必要です。パスはマシン固有
なので、コミットされる `config/app.json` ではなく環境変数 `CARDGEN_COMFYUI_MODELS_DIR`
で渡します。未設定なら空リストになり、生成は続行します。ハッシュは
`.cache/model-hashes.json` に (size, mtime) をキーにキャッシュします。

## 失敗した実行も記録する

`--count 4` の3枚目で落ちても、1〜2枚目の画像は `outputs/` に残ります。記録が無ければ
どのseedで、どのワークフローで、どの重みで出た画像なのか後から追えません。だから失敗時も
同じ `*_metadata.json` を書き出します。

`results` には完走した分だけが入ります（1枚も無ければ空配列）。例外は記録後に再送出する
ため終了コードは変わらず、`METADATA:` 行は送出前にstdoutへ出るので、標準出力を解析する
呼び出し元も失敗した実行を拾えます。Ctrl-Cやネットワーク断も同じ経路で記録します。
