# プロファイルは何をしているのか

各プロファイルが**どのモデルで、何を、どういう設定でやるか**を、生成の仕組みを
知らない人向けに書きます。数値は 2026-08-17 時点で `config/profiles/` と
`workflows/approved/` から読み取った実測値です。**推測は含みません。**

`--steps` などで上書きした場合は、実際に流れた値が実行記録
（`outputs/*_metadata.json` の `generation_settings.node_inputs`）に残ります。
**説明より記録が正です。**

## 先に、パラメータの意味

| | 何を決めるか | 上げると | 下げると |
|---|---|---|---|
| **steps** | 何回にわけてノイズを取り除くか | 細部が詰まるが遅い。ある所から変わらなくなる | 荒くなる |
| **cfg** | プロンプトにどれだけ従わせるか | 指示に忠実だが、色が濃くなり構図が硬くなる | 自由だが指示を無視しはじめる |
| **denoise** | **元の絵をどれだけ壊してよいか**（0〜1） | 別の絵になる | 元のまま。変化が乗らない |
| **seed** | 乱数の初期値 | — | 同じ seed・同じ設定なら**ほぼ同じ絵**が出る |
| **sampler / scheduler** | ノイズの取り除きかたの手順 | — | 変えると絵が変わる。比較のときは固定する |

**denoise がいちばん誤解されます。** 「品質」ではなく「**何を失ってよいか**」を選ぶ値です。
既存の絵に対して 0.35 で回すと構図は残りますが**顔は描き直されます**。0.05 なら
渡したものがほぼそのまま残り、解像度だけ上がります。

**seed は「同じ絵が戻るボタン」ではありません。** 同じ環境・同じ設定なら**絵として
同じもの**が出ますが、ファイルとしてバイト一致はしません。

## 実際に使うもの

### `esrgan-upscale` — 拡大するだけ

| | |
|---|---|
| モデル | RealESRGAN x4plus anime 6B |
| すること | 渡した画像を**4倍**にする |
| 拡散 | **通さない** |

**Sampler もプロンプトも seed も持ちません。** アニメ絵向けに訓練された拡大器で、
画素を増やすだけです。**絵の内容は変わりません。** 決定的なので、同じ入力からは
常に同じ出力が出ます（`--count` は 1 のみ）。

線がやや甘くなるのは補間器だからで、再生成しているわけではありません。

### `flux2-klein-edit` — 参照した絵を描き直す

| | |
|---|---|
| モデル | FLUX.2 Klein 4B Base（テキストエンコーダ Qwen3-4B、VAE flux2-vae） |
| すること | 渡した絵を参照して、**指示文のとおりに描き直す** |
| 設定 | steps 28 / cfg 5.0 / sampler euler / 1024×1344 |

入力画像は `ImageScaleToTotalPixels`（1.4メガピクセル）で揃えてから参照されます。

「キャラクターは維持して、舞台だけ置き換える」のような指示に向きます。
**指示文の書きかたで結果が大きく変わります。**

### `wai-refine` — 既存の絵を印刷解像度へ上げて整える

| | |
|---|---|
| モデル | WAI Illustrious SDXL v1.7 ＋ RealESRGAN x4plus anime 6B |
| すること | 拡大 → 1480×2016 へ揃える → **denoise ぶんだけ描き直す** |
| 設定 | steps 20 / cfg 6.0 / sampler euler_ancestral / **denoise 既定 0.35** |

内部の順序は `画像を読む → ESRGANで4倍 → Lanczosで1480×2016 → 拡散`です。
**比率の違う絵を渡すと引き伸ばされます。** 呼ぶ側で先に切っておいてください。

**既定の 0.35 は構図を保つ値であって、顔と発光を保つ値ではありません。**
渡した絵をなるべく残したいなら `--denoise 0.05` を明示します。

## 今は使っていないもの

元絵をこの環境で作っていた頃の経路です。**残してありますが、現行の制作線には
入っていません。**

| プロファイル | モデル | 何をしていたか |
|---|---|---|
| `wai-hires` | WAI Illustrious SDXL v1.7 ＋ ESRGAN | 1024×1344 で生成 → ESRGANで拡大 → 1536×2016 で2回目（steps 20 / denoise 0.45） |
| `wai-hires-latent` | 同上 | 拡大を latent 側（bislerp 1.5倍）で行う比較用。**それ以外は `wai-hires` と同一** |
| `wai-single` | 同上 | 832×1216 の1パス。探索用 |
| `wai-controlnet` | 同上 ＋ xinsir scribble ControlNet | ラフの線を条件に与えて構図を固定する |
| `zimage` | Z-Image-Turbo | steps 8 / cfg 1 の高速生成。negative は `ConditioningZeroOut` で無効 |

## モデルの出どころを確かめるには

実行記録の `model_files` に**ファイル全体の SHA-256** と、可能なら
`weights_sha256` が入ります。

**配布元と突き合わせるときは `weights_sha256` を使ってください。** ファイル全体の
ハッシュは safetensors のヘッダのパディング1つで変わるので、重みが同一でも
一致しません（WAI v17 で実際に起きました）。`weights_sha256` は
`modelspec.hash_sha256` の値で、Civitai の `AutoV3` と比較できます。

modelspec を持たないモデル（ControlNet など）と `.pth` は `null` になります。
**持っていない情報を持っているかのようには記録しません。**

## ライセンス

各モデルの条件は配布元で確認してください。このリポジトリはモデル本体もライセンス文も
持ちません（`config/profiles/*.json` の `approved_models` が**名前だけ**を持ちます）。

- WAI Illustrious SDXL / RealESRGAN x4plus anime 6B — Civitai・GitHub の配布ページ
- FLUX.2 Klein 4B Base / Qwen3-4B / Z-Image-Turbo — 各配布元のモデルカード

**未承認のモデルは流れません。** `approved_models` に無いファイルがワークフローに
含まれていると `cardgen.py` が実行前に落とします。
